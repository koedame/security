# koedame security contact

This repository is the place to report security vulnerabilities in websites and
services run by koedame. It contains no code.

## How to report

Please use the private report form:

**<https://github.com/koedame/security/security/advisories/new>**

- You need a GitHub account to send a report.
- The report is private. Only you and the koedame maintainers can read it.
  Other reporters and the public cannot see it.
- We will reply within 7 days to confirm that we received your report, and keep
  you updated until it is fixed.
- Reports in Japanese or English are welcome.

Please do not post vulnerability details in public places such as issues,
pull requests or social media.

## What to report here

Any website or service whose `/.well-known/security.txt` points to this
repository.

For an open-source project that has its own public repository under
[koedame](https://github.com/koedame), please use the "Report a vulnerability"
button on the Security tab of that repository instead.

## Contributions

Issues are disabled, and pull requests are not accepted in this repository.
