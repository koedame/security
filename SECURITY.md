# Security Policy

## Reporting a vulnerability

Please report security problems privately through
[GitHub's private vulnerability reporting](https://github.com/koedame/security/security/advisories/new).
Do not open a public issue or pull request for them.

We will reply within 7 days to confirm that we received your report, and keep you updated until it is fixed.

## Supported versions

This repository contains no software. Reports apply to the version of each
website or service that is currently live.

## What counts as a vulnerability

- A way to read or change another user's data
- A way to bypass sign-in or access controls
- Injection, cross-site scripting, request forgery and similar flaws in a live site
- Exposed secrets or misconfiguration that puts users at risk

## How we handle your information

- **What we receive:** your GitHub account name and what you put in the report
  (the description of the problem and any follow-up messages).
- **What we use it for:** only to check the problem, fix it, and contact you
  about it. We do not use it for anything else.
- **Who sees it:** the koedame maintainers. We do not share your report or your
  name with third parties, and we do not make them public without your consent.
  If we publish an advisory after a fix, we credit you by name only if you want us to.
- **How long it is kept:** the report stays in the GitHub security advisory
  where you sent it. If you want it deleted or your details removed, say so in
  that advisory and we will handle it there.
